# Projeto Constructor - Java

Projeto simples desenvolvido em Java com o objetivo de praticar os conceitos básicos de programação orientada a objetos, principalmente o uso de **classes**, **objetos**, **atributos**, **métodos** e **construtores**.

## Objetivo

O objetivo deste projeto é demonstrar como um construtor funciona dentro de uma classe Java, permitindo criar objetos já com valores definidos no momento da instanciação.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos
- Classes e Objetos
- Construtores
- Métodos
- Atributos

## O que o projeto faz

O projeto cria objetos a partir de uma classe utilizando um construtor.  
Com isso, é possível definir informações iniciais do objeto e depois exibir esses dados no terminal.

## Conceitos praticados

- Criação de classes em Java
- Instanciação de objetos
- Uso de construtores
- Organização básica do código
- Exibição de informações no console
